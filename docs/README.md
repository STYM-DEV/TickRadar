# TickRadar — user documentation

**TickRadar only runs on Folia.** It shows the TPS and MSPT of the region a player is standing in,
gives staff a sorted view of populated regions, and can alert your team in game, in the console and on
Discord when a region slows down.

This is the documentation for TickRadar **v1.0**, released under the MIT license.

## Support

TickRadar is a small, free, open-source plugin by **STYM**. Issues and questions go on the public
repository (link on the plugin's page). There is no dedicated Discord for support.
